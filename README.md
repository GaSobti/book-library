# Book Library Application

A React app for managing a personal book library.

## Features
- Add books
- View book details
- Update book details
- Mark books as read or unread
- Filter books by:
  - All
  - Read
  - Unread

## Technologies Used
- React
- Redux Toolkit
- React Redux
- CSS

## Steps to Run
1. Clone the repository.
2. Install dependencies:
    npm install
   
3. Start the app:
    npm start
